# Journal

Messy, dated notes on what was going on while the work happened. Each entry is a
snapshot of its moment, not a document to keep current — entries are not
groomed, corrected, or updated after the fact.

Naming: `MMDDTHH-short-slug.md`, timestamps in `America/New_York`.

This repo is public, so entries here must be safe to publish. Anything sensitive
goes in `dev/private-notes/` instead, which is gitignored: third-party personal
data, licensed vendor data, machine or path details, unpublished results, and
candid remarks about people or their work.

Promotion runs one way. A private note worth publishing gets rewritten
deliberately into an entry here or into `CHANGELOG.md`; it is never moved across
as-is.
